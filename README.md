# Tennis Scorekeeper V1

Primera compilación funcional del proyecto definido en los capítulos 1–13.

Archivos: index.html, style.css, app.js, manifest.json, service-worker.js.

## Ejecutar

Con Python:

`python -m http.server 8000`

Abrir `http://localhost:8000`.

Para PWA en iPhone, publicar por HTTPS y abrir desde Safari para agregar a pantalla de inicio.

## Pruebas internas

En la consola del navegador ejecutar:

`window.tennisTests()`

Esta primera batería comprueba reglas críticas del motor.
